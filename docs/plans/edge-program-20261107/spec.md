本板是 2026-11-07 全天策略讨论的**决议总账与补票板**：已落卷的交叉索引
+ 未成票项的正式票据。讨论主线：EV/概率/ROI 第一性 → 十年逆向选择
实证 → 四类 EV 源与六步验证门（用户校准）→ 双轨制 → 池类复式反火锅

## Problem Statement

用户判词：系统对投注策略的理解"完全不及格"——十年数据证明按 claimed EV
选注是逆向选择（单关 Q1→Q5 实现 ROI −12.9%→−17.4% 单调恶化，串关 Q5
全灭），而池类单式是分布最差票。修正后的道路：**先探索（四类 EV 源的
持续扫描）→ 再验证（六步门）→ 后执行（探针放量）**，且纸面账户要从
"EV 集中注"重构为"带来源标签的分布式探针阵列"。讨论散落五个卷宗，
需一张总账防止决议蒸发，未成票项需立即落票。

## Solution

1. 纸面策略 v2 = 探针阵列（本板票 01）：每注带 edge 来源标签 +
   每注 CLV 测量；六步门为 strategy_version 晋升纪律（票 04 落 prereg）。
2. 首批离线检验（票 02/03）：H9 模型分族、H2/H3 池份额校准——库内
   数据半天级，是探索轨最先出判决的两条假设。
3. 其余决议已在卷（见 Further Notes 索引），本板不重复。

## User Stories

1. 作为账户所有者，我想要每注带边缘来源标签（信息差/校准/市场选择/
   微观结构/校准探针），所以账本能按来源分别结算盈亏，哪个方向真有
   边际一目了然。
2. 作为账户所有者，我想要每注自动记录 CLV（入场价 vs 源T 收盘锚），
   所以不用等几百注赛果就能用市场裁判测量"入场价是否系统性占优"。
3. 作为账户所有者，我想要策略版本晋升必须过六步门（来源声明→校准→
   CLV 审计→全成本→分数 Kelly→显著性），所以任何放量都有完整证据链，
   不再被 claimed EV 自我证明欺骗。
4. 作为研究者，我想要胜负族与进球族模型分开检验（H9），所以 λ 误差
   不再污染全部玩法，一族差可以只停一族。
5. 作为研究者，我想要源B 849 行历史份额对账结果（H2/H3），所以
   Ottaviani-Sørensen 理论（份额低估热门/平局低买）在 JC 池有没有
   实证，一翻便知。
6. 作为研究者，我想要市场校准日扫与十年桶漂移监测（S1/H8），所以
   市场侧结构的当代变化自动留痕。
7. 作为账户所有者，我想要池面敞口按测量目的定规模（缩编 A/B 裁决），
   所以纸面成本花在测量产出上而不是体验敞口上。
8. 作为运维者，我想要假设注册表冻结即不可改（H-id 纪律），所以
   探索轨的结果不会被事后挪门美化。
9. 作为研究者，我想要周度 agent 循环读台账提新假设、人审后注册，
   所以探索是持续机制而不是今天一次性的手工分析。
10. 作为账户所有者，我想要 2串1 组合头分散与去相关规则（修订④），
    所以组合层不再被单一观点垄断。
11. 作为研究者，我想要分玩法抽水表（R2），所以高 vig 玩法的 EV 门槛
    有校准，+100% 的比分 EV 不再与 +20% 的胜平负 EV 混为一谈。
12. 作为账户所有者，我想要纸面账户主指标（EV 实现差）随月读自动
    报告，所以"当代模型还差多少 pp"这个问题每月有数字答案。

## Implementation Decisions

- **票 01（策略 v2 探针阵列）**：auto-paper 板票 03 的策略层重构输入；
  bets 增来源标签与 CLV 列（迁移同车）；探针组合=校准 ¥6/晚 +
  陈盘触发 ¥2 + 滚存期 ¥2 + 价格带 ¥2（随扫描器点亮逐个启用）；
  池面敞口已裁（2026-11-08）：**A=¥20/晚测量帽**（auto-v2 探针时代
  纯测量定位；auto-v1 冻结版 64/128 帽不受影响），随 prereg 修订⑤落。测试主缝=每日编排 flow 整跑（票 03 同缝）+ CLV 报告面。
- **票 02（H9 分族检验）**：纯离线研究票——十年回放训独立 totals
  估计器（Poisson/npxG 特征），与矩阵 ttg 视图比分族 Brier；差距
  >2SE 才立 ADR-0006 修订票。产出=报告（research 笔记），无代码面。
- **票 03（H2/H3 份额检验）**：源B 849 行 × 开奖结果，份额校准表+
  平局低买检验；同样纯离线报告票。
- **票 04（prereg 修订⑤）**：六步门+来源声明纪律落 prereg B 节
  （首跑前窗口 11-11 前），纯文档票。
- 扫描器/台账/agent 循环=autoresearch 板（票 01-05 已在），本板不重开。

## Testing Decisions

- 好测试只钉外部行为：探针标签落账、CLV 数值 vs 收盘锚口径、
  flow 整跑幂等（auto-paper 票 03 先例）；离线检验票以报告数值
  对账历史手工版为验收（今日十年扫描=基准）。
- 无新缝：全部复用 flow 整跑缝与报告面缝。
