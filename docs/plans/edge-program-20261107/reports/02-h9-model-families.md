## 裁决：**refuted**——独立进球族估计器不优于单矩阵派生 ttg 视图
（配对 Brier 差 |z|<1，远不及 >2SE 门）。**不开 ADR-0006 修订票**，H9 记
refuted 留痕。

## 设计（同期同分母）

- 分母：金表 match_features 2019-08…2026-07（avgc 1X2 + FD OU2.5 收盘在场），
  双队 understat npxG 史（每队 ≥6 场，严格 PIT 只取开球更早场次）+ GLM 训练
  预热 ≥400 行 → **12,849 场**配对。
- **A 矩阵 ttg 视图**（单矩阵基线）：生产 canonical 市场侧联合矩阵（票 23
  转正路径：avgc 1X2 fair（Shin 去水）+ FD OU2.5 去水 P(over) → joint_lambdas
  NLS → ScoreMatrix.ttg()）。
- **B 独立 totals GLM·市场版**：Poisson GLM（log 链，scipy L-BFGS，xg_dc.py
  同款），特征=OU 市场面（fd_avgc_ou 去水 p_over + srct OU 收盘线）。
- **C 独立 totals GLM·全特征（票文主估计器）**：B + understat npxG 双队
  滚动速率（12 场窗）log 特征。
- 训练纪律：周度 walk-forward（ISO 周一界），周内预测周后入训。
- 指标：ttg 八档（0..7+）多类 Brier 配对差 + 分档校准分箱。

诚实注记：模型侧 DC 矩阵未重跑十年 walk（其 1X2 面已十年否定 RPS −0.04，
ttg 面是同一 λ 机器下游）；市场侧联合矩阵是当前生产 ttg 定价面，为「单矩阵」
最强代表——基线取强不取弱。

## 判读边界（防过度解读）

- 本票答的是「分族是否带来**数学精度增益**」——答案否。015 案例式的
  「一个坏 λ 观点同时污染四面」是**操作风险集中**论证，不是精度论证，
  Brier 打平不反驳风险论——但按票文门（差>2SE 才开修订票），ADR-0006
  维持单矩阵 canonical。
- 胜负族对照（票文可选）未跑：1x2 十年基线已有（RPS −0.04 vs 市场），
  重点在进球族已答。
- H9 台账状态：refuted（进球族精度增益不存在，量级 <0.0001 Brier）。
