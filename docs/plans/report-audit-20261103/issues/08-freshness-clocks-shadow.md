# 08 新鲜度分时钟 + 300s 并行测量

Type: task
Status: resolved (PR #222, 2026-11-04)

## Question

竞彩资格年龄只看源调盘时刻（300s 规则）：观测再新、价未变也拒——"价格没变"
与"很久没确认"混在一个钟上。是否分时钟记录展示，并对新旧判定做并行测量
（**不改规则**，规则现状见 map Notes）？

## 事实（2026-11-03 main 实测）

- `data/quote_evidence.py:106-113` `effective_source_updated_at` = sporttery
  调盘时刻（`captured_at`，源语义）；808-818 `age > 300s → stale_source`；
  `DEFAULT_FRESHNESS_SECONDS = 300`（40）——观测龄不参与年龄
- 隔离构造坐实：10 秒前刚重新观测、在售、价约 1 小时未变 → 仍 `stale_source`
- 对照：EU 段已按**观测龄** 60min 闸（`EU_AGE_MAX_SECONDS = 3600`，PR #189
  票 02 人裁决）——两段口径本就不对称
- `tests/unit/test_quote_evidence.py:167-184` 钉死 300s 边界（含 301s stale）

## 验收

1. 五时钟分离记录与展示：最近成功确认观测 / 价格持续未变时长 / 销售状态
   最近确认 / 国际参考最近观测 / 两源配对时差
2. 影子判定：裁决同时输出规则口径（300s 调盘龄）与观测口径（观测龄）两份
   结论 + 差值入库（仅记录，`stale_source` 默认行为零改动）
3. 晨检 / 面板报告双口径下的有效覆盖差异，供读数
4. 300s 边界既有测试不动；影子数据落库须可区分（不污染正式判决字段）
