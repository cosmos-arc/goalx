# 09 平局处理方法谱系（排平/降权/消解）与 JC 翻译

Type: research
Status: resolved

## Question

想法来源：用户 2026-11-09 提示——「业界有很多类似排除平局的方法，对很多赛事很有效果，可以研究此类方法」。

业界与民间对**平局这一最难结局**的处理方法谱系是什么？对各类赛事的实证效果与适用条件？

1. **国内民间**：胜负彩 14 场构票的排平/去 1 法（不确定腿只包 3/0 不包 1）——效果主张、命中率损失 vs 派彩结构的真实账、社区宣称的适用条件（强弱分明轮次/高分联赛/收官轮）。
2. **海外 pools 史**：英国经典 football pools 本质=选平局（score draw 计分）——人群平局行为的结构性差异（与我方 E-24 中国池**高买**平局 +6.7pp 对照：是市场结构差异还是游戏规则差异）。
3. **学术**：平局可预测性文献——为何平局是最难预测结局（泊松类系统性低估/联赛平局率结构/低分联赛效应）、近年 ML 对 draw 的处理（放弃 vs 显式建模）。
4. **fixed odds 类比**：Draw No Bet、double chance、亚洲让球盘的平局消解机制——哪些在 JC 可购面有对应物（had 必须面对 1X2 三选一、串关排平=只串胜负）、哪些不适用。
5. **翻译到 JC 池面**（重点）：与 E-24（人群高买平局 → 排平=反人群方向）+E-25（滚存期一等奖结构 +45%）+E-23（热门低估 directional）合成的**池面反人群构票族**：cell EV=fair/share×0.65，绝对正 EV 需背离 53.8%（E-22 十年 max 49.2% 不可达），可测判据只能是「相对改善+滚存期条件化+二/三等奖层结构」——按 E-26 教训用尾部派彩感知目标函数，不用每元期望注数。
6. **冲突检查**：E-22（池面结构性出局）、E-24（平局警戒带已进 P0 投影器）、E-26（池类默认负 EV，敞口只按测量目的定规模）。

产出：`research/09-draw-handling-methods.md`——方法谱系表（证据强度×适用条件×量级）+ JC 翻译矩阵 + 可证伪判据（预期哪些联赛/轮次/滚存条件下排平相对收益最大）+ 与 S5 真终局份额/官方注数的联动读数设计（供 §5 登记人裁）。

## Answer

**研究笔记**：`.scratch/edge-audit-20261109/research/09-draw-handling-methods.md`（谱系表 M1–M11 + 翻译矩阵 + 判据 J1–J4 + S5 联动读数 R1–R3 + 两级来源清单）。

1. 「排平」实为三族：民间构票层双选 30（轶事级，无一可复现主张）、海外 fixed odds 消解产品（DNB/DC/让球——JC 无对应物，不适用）、以及**方向相反**的民间平胆法；平胆谚语（「得平局者得足彩」）+ 一等奖全中制的对冲压力恰是 E-24 高买平局（+6.7pp）最可信机制——排平=反人群方向成立，但民间「排平技巧」本身全部不可证。
2. 结构对照（一手核验）：英国 Treble Chance 以 score-draw 计分**强制选平**（返奖仅 25–50%）；同构的西班牙 La Quiniela（1X2 parimutuel、takeout 45%、滚存）人群**欠买**平局——证明 1X2 池结构不决定平局方向，E-24 反向为中国市场特异（文献先验须本地重验，§3.13 再添一例）。
3. 学术共识：平局最难（Dixon-Coles ρ 低分修正、ML 几乎从不把最高概率给平局、不少研究直接剔除平局做二分类）——「排平判别」上限低，只能建立在赔率带基线偏离上。
4. JC 翻译唯一合法形态：E-24×E-23×E-25 合成的「热门倾向+条件化排平」族，滚存期条件化，E-26 尾部派彩感知目标下评估**相对改善**（E-22 封顶，绝不许转正表述）。
5. 判据：J1 联赛平局率结构（在库立即可测，MDE≈1–1.5pp）、J2 排平判别力（在库 1–2 季窗）、J3 反人群族相对改善（回放先行+真终局定案，滚存 355 期/非滚存 1,268 期均过 n≥200 门）；S5 联动读数 R1–R3 供 §5 登记人裁。
6. 冲突检查全过（§5 表）；新增方法论警示：Hubáček「去相关可获利」迁移到 35% takeout 池面只剩排名改善含义，引用须带折扣注记。
7. 来源两级标注：9 项直接核验（含对「Forrest & Pérez 欠买平局」检索转述的一处更正）、6 项检索摘要、3 项如实标缺（澳客被内容过滤拦截、ML 期刊版付费墙、Oxford Handbook 章节未获取）。
