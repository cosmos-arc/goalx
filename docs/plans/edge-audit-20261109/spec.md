# Spec: edge-ledger 全面复审（可信度审计）——执行阶段

Status: ready-for-agent
Wayfinder 图：`map.md`（决策索引，决议详情在各票）；本 spec=执行契约。账本纪律（append-only / 阴性措辞 / 判决词六枚举）优先于本 spec 一切条款。

## Problem Statement

`docs/plans/edge-ledger.md`（38 条，E-38=本审计自身）是全部正 EV 与定价差异探索的唯一登记处，其判决门控着整个研究程序（真金阶梯、池面方向、扫描器运行）。2026-11-09 两路独立审查（本图研究批 04/05/06/09/11 + 外部审计 @032324c）发现：七处已坐实的实现缺陷（影响读数或证据资格）、一处来源级数据断点（FD Pinnacle 2025-07-23，官方警示已逐字核验）、判决词功效不对称嫌疑（多条 refuted/阴性判决的 n 只够排除大效应）、以及运行前提过期（2026 取消正午分界线）。在账本结论继续作为策略地基之前，必须：修复→定点重算→功效审计→溯源核验→第一性数据矩阵→append-only 回写。

## Solution

一个有界的执行阶段，六张工作票按既定序（**10 定修重算 → 03 功效审计 → 01 溯源核验 → 02 载重复算 → 07 数据矩阵 → 08 合成人裁**，一会话一票）完成后：全部坐实缺陷修复并三轴过审、受影响读数出新旧差对照、每条判决带 MDE 分级、37 条溯源零断链、缺口×补法矩阵带优先序，最终一次性 append-only 回写账本（判决词修订/§4.1 增补/§3 新教训/§5 候选五族/E-38 收口），审计报告归档 `docs/plans/edge-audit-20261109/`（保留相对布局维持交叉链接）。

## Implementation Decisions

- **交付形态**（人裁 2026-11-09）：票 10 全部修复合一个 PR，生产行为变更（账户聚合/预筛资格）与研究脚本修复同车，三轴审查全走（/implement 内嵌 code-review + correctness-review skill）；不合零碎 PR。
- **执行序**（人裁）：10→03→01→02，随后 07（等 03）、08（等 01+02+07+10）；一会话一票（research 票除外，已全毕）。
- **结算语义**：仅「7+」档按 ≥7 计命中（0–6 档维持 ==k）；不动产品结算面，只动研究脚本。
- **OU 锚语义**：每书取其最晚合格赛前报价（pre/early+sane 带过滤保留），再跨书均值；装载结果附书覆盖数与报价年龄；docstring 与实现对齐。
- **BH 家族语义**：校正家族=该轮进入验证的全部候选（先筛后校的顺序废除）；E-32 协议措辞同步钉死；跨 facet 是否分家族按预注册族定义统一。
- **账户面**：税=复用既有期次归集机制（同人+同期+同游戏合并后套税函数，竞彩期=票内最晚比赛编号日期）；sample_sufficient 分母收窄为已结算且合格且按场独立的暴露数；CLV 聚合按场聚类（同场多锚并一）。点估计与资金规则一致性：报告同时给等注口径与按场口径。
- **资格链**：预筛按玩法（had/hhad/ttg/crs/hafu）分别查在售状态与单关资格；下游建注资格链补玩法级验证；玩法资格未齐前，相关记录不自动视为正式可执行策略证据。
- **FD 断点处置**：回看=涉 Pinnacle 列（PSC/PAH 系）与 Avg/Max 成分变化的读数带「2025-07-23 断点」注记并隔离重算受影响段；前瞻=盘点全部 Pinnacle 锚供给路径（fdhist/源T/odds_api/propline），给出六步门③主锚前向定义建议（留票 08 裁）。
- **重算纪律**：独立代码路径（不复用原报告脚本）+冻结真树只读+新旧差对照表；差异解释到记录级；判读按账本判决词如实落，禁止顺手升级。
- **功效审计**：闭式 MDE 为主（与 E-30 σ 推导交叉验证），配对结构按配对公式；产出「判决×n×结构×MDE×类别」表与降级/加注清单（人裁后回写）。
- **数据矩阵**：从假设推导最少充分数据集（字段/覆盖/时点/PIT 要求），与现持有 diff；补法四档+优先序=预期信息价值÷补缺成本；§4.1 十条作为起点重新推导不照抄。
- **回写纪律**：一次性人裁后落账——更正=追加行不改写冻结条目；§0 计数刷新；报告归档 docs/plans/edge-audit-20261109/ 保留 .scratch 相对布局；账本与图改动随收官 PR 进 main。
- **跨板边界**：E-14 拍点重验已开 autoresearch 票 12（不属本图）；S1 p10-20:d 晋升人裁属周循环；EM-1 扩族属 autoresearch——本审计不执行任何新探索。

## Testing Decisions

- **好测试只测外部行为**：结算语义（7+ 档喂总进球 8/9 的回款断言）、OU 聚合（合成多书多时刻报价，断言=每书末价均值而非最后更新者，含书覆盖与年龄字段）、BH 顺序（合成 20 候选 p 值组，断言家族含全阴候选）、税期归集（同期两笔 6000 → 税 2400 而非 0）、sample_sufficient（200 条未结同场记录 → false）、CLV 聚类（同场复制行的 SE 按场收敛）、资格门（ttg 停售+不允许单关 → 拒绝）。
- **接缝（全为既有接缝，不新造）**：①研究脚本接冻结库只读面+试验台账 CSV（重算与差对照的出入缝）；②账户面在既有读面函数层测（不进 SQL 细节）；③资格门在预筛函数层测；④回写=人裁环（HITL，票 08），不写自动回写。
- **先例**：仓库测试纪律（测试文件 ANN/D 豁免、gold/指纹回放测试、correctness-review 惯例）；外部审计的合成反例（p 值组/复制行/同期两笔）直接转正为测试用例。
- **重算验收**：新旧差对照表无未解释残差；差异能追到记录级才算过。
- **功效验收**：MDE 表与 E-30 闭式推导抽样交叉验证一致。
