# 05 新增价值评测口径

Type: grilling
Status: resolved (2026-09-19)
Blocked by: 03

## Question

spec v1.1 的证明义务如何操作化："LLM 先证明少量带来源/时点的情报有新增价值"。本票定评测协议：

1. **指标**：RPS / 校准（vs ML-only 与 Fused）、分歧场次命中率、情报时点质量（来源/时间戳齐全率）。
2. **样本与周期**：多少场次/多少周才算"证明"或"证伪"；样本不足如实记录（沿用票 34 的诚实边界）。
3. **盲评**：是否引入人工盲评（用户看 ML 摘要 vs LLM 证据卡盲选），流程与频次。
4. **失败路径**：证伪后融合线降级/停用的判据。
5. **复核队列口径**：何种分歧入场，复核结论如何回流评测集（旧图定过"复核只进评测集"）。

## 不变量与人裁决项

- "证明"的阈值（指标+样本量）由用户裁决后冻结，不许事后放宽。
- 无数据/样本不足 = 未证明，不得默认通过。

## Answer（2026-09-19 HITL grilling，四项全按推荐）

实测基础：metrics.py 已有 RPS（penaltyblog 交叉验证）/Brier/log-loss/ECE/skill/**DM 配对检验（HAC）**全套现成；ML 预测健康日产量 13-27 场/日（serve 中断日为 0），配对样本现实速率 50-120 场/周。

1. **两档证明阈值（冻结，事后不得放宽）**：
   - **Tier A 融合线去留**：≥200 配对场 + ≥6 周窗口；Fused 配对 RPS 胜率 ≥52%；LLM 线 ECE 校准无劣化（vs ML 线同期）；DM p 值如实报告、不设门槛。达标 → 线保留；不达标且（胜率 ≤48% 或校准劣化）→ 证伪路径。
   - **Tier B 真钱切换（对齐票 04 冻结）**：整赛季 + ≥500 配对场 + DM p<0.05 + 复核无系统性错误 + 盲评定性不负面；缺一不可，任一缺失 = 未证明。
   - 样本不足/无数据 = 未证明，如实记录（票 34 诚实边界沿用）。
2. **盲评（定性参考列）**：双周一次约 10 场，匿名顺序呈现 ML 摘要 vs 证据卡二选一，结果进报告参考列，不作任何档证明支柱（单人盲评统计力弱）。
3. **证伪处置**：停 analyst（省钱）、scout 采集继续存证（情报数据资产近零成本，将来复跑免费）、fused 停止生成；重新开线 = 新一轮评测协议（阈值重新冻结）。
4. **复核队列（双路自动入队）**：赛前 = gate JS>0.06 的 Tier1 场次；赛后 = 结算"一对一错"场次（ML 对 LLM 错或反之）；复核结论三分类（情报关键贡献/无关/误导）回流评测集作分歧场细分维度；"复核只进评测集"维持——不改任何预测工件。
5. **情报质量列**（实现随票 07 拆票）：覆盖率/时点新鲜度/来源多样性——报告列，不设门槛。
