## Problem Statement

回测引擎（M2，票 28/ADR-0007）只吃过五大三季（约 6,174 场）+ fdhist 单源欧赔，
诚实结论是 skill -3.75%。现在数据面已质变：源T 史窗 2016-01-01 起 pending=0、
fixture_universe 48,561 场（11 重叠联赛×11 季）、odds_change_event 139.3M 事件
（gap=0）、亚盘/大小球 11 家模板书商十年全覆盖、xG 双源、自算 Elo 十年逐场——
但引擎没吃到这些。同时盘点钉死三个前提：①1x2 轨迹 2023/24 才有，十年欧赔收盘
只能以 fdhist PSC/PSH/AvgC 代理（时代分层）；②fdhist 存在行政判赛场（土超 2023
地震两队/2025 阿达纳退赛，"3-0"从未踢过）与 PSC 新近场未成熟（滞后约 5 个月）
两类污染源；③2016-2019 四季的技统/阵容特征还锁在旧模板页里（19,878+5,841 张
raw 完好，解析器不认）。用户需要：在这套十年数据上重跑模型与策略验证，知道
"模型到底有没有 skill、edge 在哪个时代/联赛/玩法"，并给出下一迭代的方向裁决。

## Solution

分四相推进的单程序：

- **A 数据前置**：旧模板解析器 v3 救回 2016-2020 特征面；行政判赛显式排除表；
  PSC 成熟度纪律（<6 个月视为暂定）。
- **B 特征面（gold）**：语料树 gold/ 落数据集（版本戳+幂等+无前视断言），
  覆盖 AH/OU 收盘族特征、时代分层欧赔收盘、xG（源纪律）、Elo、fdhist 扩展列。
- **C 引擎 v2**：既有回测引擎扩窗十年 walk-forward（周重估时间衰减 DC 保留、
  无前视断言常开），训练集卫生接线，hhad/ttg 用真实 AH/OU 收盘线解锁判定，
  market-λ 联合反推 P1。
- **D 评估**：分时代/联赛/玩法的十年技能评估 + CLV 十年仪表盘 + 蒸发分析报告。

全程门=报告+用户点头：hhad/ttg 是否启用、market-λ 是否转正、下一迭代方向，
都由数据对照报告交用户裁决，不自动放行。

## User Stories

### A 数据前置

1. 作为量化负责人，我要旧模板 detail 页（19,878 张，2016-2019+2020 尾）解析出
   技统/事件/阵容/阵型进 bronze/silver，让 2016-2019 四季的技统与阵容特征从
   零变全覆盖。
2. 作为量化负责人，我要旧模板 analysis 页（5,841 张，2019-2020）按既有数组
   数据模型（h_data/v_data 等）解析入库，让近况/交战特征向前多覆盖两季。
3. 作为量化负责人，我要解析器 v3 与 v2 并存（版本函数隔离，v2 行不动），
   bronze 追加走既有回补通道，重物化沿用独占窗口铁律。
4. 作为回测用户，我要一张显式的行政判赛排除表（队×日期窗，含土超 2023 哈塔伊/
   加济安泰普、2025 阿达纳德米尔斯波，可续添），训练集与对账集都自动剔除这些
   "比分是真的、比赛是假的"场次。
5. 作为回测用户，我要 PSC 成熟度纪律硬规则：开球后不足 6 个月的 fdhist 行
   PSC/PSH/AvgC 视为暂定，不进 fair 基准与校准，防止新近场未收敛数值污染
   （2026-02 起零行实证）。

### B 特征面（gold）

6. 作为模型维护者，我要 gold 特征数据集骨架（语料树 gold/ 下、_meta 版本戳、
   幂等重建、输入 silver 版本钉死），让特征口径可追溯、可复现、跨次一致。
7. 作为模型维护者，我要 gold 构建带无前视断言：逐特征行声明其用到的最大
   时间戳并断言早于开球（PIT 纪律），违规即构建失败，不靠自觉。
8. 作为策略研究者，我要 AH/OU 收盘族特征（11 家模板书商逐场）：终盘线/水、
   初盘→终盘漂移、多书共识与分歧度、盘前后相位（early/pre/inplay）、
   临场（开球前 1h/24h）报价切片。
9. 作为策略研究者，我要欧赔收盘特征时代分层：2016→2023-24 前用 fdhist
   PSC（收盘代理）/PSH（开盘）/AvgC；2023-24 起用语料轨迹派生收盘
   （cid177 锚 + 多书共识），断层在特征里显式标注 era 字段而非静默拼接。
10. 作为模型维护者，我要 xG 特征按源纪律生成：Understat（2014+）为主源、
    源T stats（2024/25+ 稳定）为近代源，单场严禁混源，每行带 caliber 源标记；
    2023/24 非五大缺口诚实留空不补。
11. 作为模型维护者，我要自算 Elo（票 78 elo_silver，十年逐场赛前值）接入
    gold 特征，作为 DC 之外的状态先验对照。
12. 作为策略研究者，我要 fdhist 26 扩展列（最高/最低/均值/开盘等）按成熟度
    纪律进特征，供 overround/价格形态研究。

### C 引擎 v2

## Implementation Decisions

- **目录与归属**：解析器 v3 落 `data/ingest/srct*.py`（版本函数制，v2 不动，
  BRONZE_VERSIONS bump 走既有重物化）；gold 构建器落 `data/`（silver 同款
  builder 模式 + OWNERS 登记）；引擎改造落 `evaluation/backtest.py`；
  行政判赛排除表落运行面显式表（data 域拥有 SQL）。遵守 ADR-0008 领域包
  拥有各自表 SQL。
- **时代分层常量集中**：断点=1x2 轨迹起点 2023/24（实测 2023-24 起步 115 场/
  2024-25 全季 4,491 场），era 定义集中在 gold 构建器一处，下游只读 era 字段。
- **gold 数据集形态**：语料树 gold/ 下 parquet（fixture 粒度一行一场、特征列
  平铺 + _meta 版本戳 + 输入 silver digest 钉死），duckdb 只读桥加视图；
  回测经 duckdb 只读消费，永不经由运行面倒手（ADR-0011 只读桥纪律）。
- **行政判赛表**：(league, team, date_start, date_end, reason) 显式行，
  fdhist 对账集与 gold 训练行两侧统一引用；续添只 INSERT。
- **PSC 成熟度**：实现为统一谓词（开球日 + 6 个月 ≤ today 才可用），
  fair 基准与 haircut 校准共用，gate② 复查沿用同谓词。
- **解析器 v3 语义**：旧模板 detail=技统+事件+阵容块（无 xG 段——真无，空≠无）；
  旧模板 analysis=与新模板同构的 JS 数组面；守卫标记沿用"页内标记"惯例，
  门⑤ TEMPLATE_MARKERS 同步登记，重物化后重跑判门验证幂等。
- **hhad/ttg 与 market-λ**：先报告后启用（数据对照 → 用户裁决 → 才进引擎
  下注面），默认维持 had-only，不因数据可用而自动放宽。
- **编排**：不新增常驻服务/deployment；重物化与 gold 重建走 CLI + 一次性
  Prefect flow（既有模式），bronze 单写者与重物化独占窗口铁律沿用。
- **代称红线**：代码/文档/输出一律 cid+分层角色代称，真名只留语料 silver
  与 .env/research。

## Testing Decisions

- 只测外部行为：解析器=纯函数喂旧模板 HTML fixture（真树样本脱敏改制）；
  gold=合成语料树全链（test_corpus_gate 的 MockTransport 攒树模式复用）断言
  版本戳/幂等/era 标注/无前视断言触发；引擎=既有 evaluation 测试先例
  （run_id 幂等、结算口径、无前视断言），扩十年窗口与卫生接线的行为断言。
- 行政判赛表与 PSC 成熟度谓词各配正反用例（剔除生效/正常场不误伤）。
- 先例：`tests/unit/test_ingest_srct*.py`（解析器版本制）、
  `tests/unit/test_corpus_gate.py`（合成树全链）、`tests/unit/` evaluation
  既有引擎断言。
- 回测十年窗一致性：抽样周重放（同输入同 run_id 输出逐字节一致）。

## Out of Scope

- 实盘/纸面闭环推进（票 37 合格销售日累计照跑，不在本程序改）
- NewsShock 信息层抽取器（P0 候选另开，214K 卫报语料就绪）
- 彩池份额投影器 P1、足彩池结构验证
- Web 工作台/报告页面改版（报告先落语料树 reports/ MD/JSON）
- uniform_res/竞彩回填链、判门口径外日期窗精化（低优先打磨）
- 模型栈扩展（四模型/blender/PIT horizons 出图）——本程序先答 DC+特征够不够

## Further Notes

- 顺序与依赖：A 相三件无相互依赖可并行；B 依赖 A4/A5（卫生谓词）不依赖
  A1-A3（特征救回可后补重物化）；C 依赖 B；D 依赖 C。A1-A3 完成后需一次
  重物化+判门复查（模板外桶应清零/锐减）。
- 2025/26 门② median 1.3% 为 PSC 未成熟轨迹（逐月收敛实证），PSC 成熟度
  纪律落地后自然消解；2026-02 起 PSC 零行待源回填，不阻塞（成熟谓词会
  自动放行补齐后的行）。
- 十年欧赔收盘=PSC 代理时代的已知局限：PSC 为收盘代理口径（非轨迹末价），
  与语料轨迹派生收盘的差异在 era 对照报告里量化一次，不逐场调和。
- 预算：解析器 v3 重物化零网络（raw 全在）；gold 重建纯本地；无新采集。
