## 裁决（2026-10-16 用户委托，按实现者推荐）

- **扩样预算=一次性全量 480 场**（`--fixture-budget 480 --limit 2000`，
  两季=裁决⑥赛季窗）。理由：480=收敛表全部可检验分母，一次性取完
  预注册全集，避免分批"看一眼再继续"的可选停止偏倚；scout 档成本
  ~1384 次调用个位数元，非约束项。**无论信号门结果如何，不设第二轮
  扩样**（"证据不足"不构成追加预算理由——票面纪律）。
- **away 全量终审预注册**：扩样跑完+news-signal 重跑后的信号门读数
  **即终审结论**（判据已实现=主结论面 CI 整正/整负/跨零，先于看数
  定死）。支持→away 转候选信息线（经济门仍归 B 相前瞻样本）；否定
  或证据不足→away 方向冻结归档，不再投入。执行待用户点头（本裁决
  只定规则与预算，不启动跑）。
