## Answer（2026-10-16 实现者裁决与发现）

- **概率档粒度=五分位**（band 0.2）：52 场样本下十分位匹配不上率
  过高；粒度与全部匹配参数进报告 payload `match_params`（随 run_id
  落盘可复现）。
- **不匹配处置=剔除并计数**（不放宽档位）：字段
  `unmatched_event_samples`（单位=fixture×side 样本，非"场"——同场
  双侧均不匹配计 2）。
- **时距方向勘误（重要）**：票面验收"重算后时距面整体上移约 8h"与
  spec US4"实际更长"均为**符号错误**。实证（kickoff 小时分布 vs 英超
  真实开球时刻，19:30/22:00/00:30=北京墙钟）确认 kickoff_iso=北京
  墙钟；旧口径 `replace(tzinfo=UTC)` 标签替换把开球时刻抬高 8h →
  旧时距**高估** 8h；真转换（`data.fixtures.beijing_naive_to_utc`
  单一真相源，与抽取器 `_kickoff_instant` 共用）后时距面**下移** 8h：
  真树重算中位 47.5h→39.5h、p90 74.0h→66.0h。"主反应窗未测"的判读
  注意仍然成立且更严（窗更近临场）。
- **真树重跑结果**（run=15，与基线 run=5 预测面逐行一致 33883 行）：
  137 事件 / **独立场次 51**（票面 52 场有 1 场无引擎预测，诚实剔除）/
  fixture×side 样本 56；主面 h 侧 diff −0.23pp、a 侧 diff +7.7pp
  （匹配对照 n=142/25，周分块 bootstrap 区间均跨 0）；事件加权旧口径
