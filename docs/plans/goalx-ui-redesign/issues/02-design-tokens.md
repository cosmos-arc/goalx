# 02 · 设计语言与 token 体系

Type: grilling
Status: resolved

## Question

goalx 的设计语言基调与 token 体系长什么样？需裁决并产出可直接进实现票的定义：

1. 品牌调性关键词（如"冷静、数据可信、专业但不高冷"）与字体栈（中文优先）
2. 语义色体系：功能色（成功/警告/危险/信息）+ 领域色——盈亏涨跌的用色惯例
3. 数据可视化色板：EV 热力编码、概率呈现、多系列曲线、浅/暗两套各自的可读性
4. 密度档位：专业表格（今日场次）与卡片（Dashboard）的间距/字号 token 分层
5. 双主题 token 结构：CSS variables + Tailwind v4 `@theme` 的落地方式，禁止页面级散写色值

## 不变量与人裁决项

- 红涨绿跌 vs 绿涨红跌：中文金融惯例红涨，竞彩/体育站混用，面向中文用户须用户裁决
- 双主题必须共享同一 token 结构；语义 token（如 `--color-profit`）而非原始色值进组件

## Comments

- 2026-09-16 预裁决（用户）：**红涨绿跌**——盈/正向用红、亏用绿。依据：目标用户为大陆竞彩玩家，颜色直觉由 A 股系产品（东方财富/同花顺/雪球）定型。配套硬约束：盈亏数字永远带正负号 + 等宽数字（颜色仅辅助，红绿色弱可读）；红绿不用纯饱和色，浅/暗主题分别调对比度；token 用语义名 `profit`/`loss`，未来出海加设置切换（Moomoo 先例）。
- 2026-09-16 预裁决（用户）：**品牌调性 = 克制、可信、专业**。克制=颜色只承载含义、九成中性色、无装饰；可信=等宽数字、口径透明、坏消息同样醒目；专业=密度服务工作流，用分层解决简单/专业矛盾而非砍字段。对标 Linear/Stripe 的安静有分量。此三词为色板/圆角/密度/字体决策的评判标准。

## Answer

2026-09-16 定稿（预裁决 + 草案过审）：

1. **字体**：`"Geist Variable", "PingFang SC", "HarmonyOS Sans SC", "MiSans", "Microsoft YaHei", system-ui, sans-serif`——拉丁/数字 Geist，中文走平台原生，零中文 webfont；数字统一 `tabular-nums`，不配等宽字体。
2. **双层色彩语义**：钱层 `--profit`（red-600/400）`--loss`（green-600/400）只用于盈亏数字与曲线，永远配正负号；界面层 `--warning`（amber：EV 偏差/数据异常/紧迫倒计时）、`--info`（blue：**可投徽章**——刻意不用绿，避免与亏损数字同屏互抢语义，且"许可≠必成交"）、`--destructive`（red：拒绝/危险操作）、`--success`（green：操作反馈，与钱层不同场景）。
3. **图表五色**：blue / orange / teal / indigo / slate（浅 600 暗 400），避开钱层红绿；概率单色蓝深浅，|EV|≥5% 打 amber 标记不做连续热力。
4. **密度两档组件级**：`compact`（数据表 13px / py-1.5 / 行高 ~36px）与默认舒适（14/16px / 24px padding），表格组件 `data-density` 变体，不做全局开关。
5. **不动项**：base-nova 纯灰中性阶与近黑 primary 原样保留；圆角 0.625rem → 0.5rem。
6. 双主题结构沿用票 11 落地的 `.dark` + `@theme inline` CSS vars，新增语义 token 进同一结构。
