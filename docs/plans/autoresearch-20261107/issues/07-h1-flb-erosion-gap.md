# 票 07 · H1 FLB 侵蚀差：JC 收盘 vs 欧收盘十年双源对比

Status: resolved（2026-11-08 批次 α；verdict=**refuted 方向反转**，报告
`reports/07-h1-flb-erosion-gap.md`，脚本+原始输出同目录）
Ref: research/61 H1（S1 扩展·双源校准）；裁决见本板 `gate-adjudication-20261108.md`

**判读摘要**：12,650 场配对（85% 链接，比分验证）；长赔带侵蚀差 −4.67%
±0.12%，但差中差 +1.45pp（z=+11.9）与 H1 机制预测**反号**——JC 相对平水
基线长赔更松、热门更苛（psc/srct 锚同构）。字面门（差>2pp、n≥500/向）
虽过但由均一抽水驱动、无判别力；「JC 收盘保留超额 FLB」不成立，假想 EV
口径 −2.5%±6.2% 无正 EV 证据。supported 才开探针票 → 不开。

## 假设（可证伪，注册表原文）

**H1 JC 收盘价保留 FLB：JC 长赔向实现 ROI 显著低于欧收盘同向（侵蚀差
>2pp）。** 机制=欧盘有聪明钱入场纠正（2026 MLB 证据：FLB 开售价存在、
收盘价消失），JC 是单一慢运营商无聪明钱流入 → JC 收盘可能保留更多长赔
高估。我们十年扫描已见 JC 单源长赔高估 3-4pp（扣水后最好桶 −6%）——
本票问的是**两源差**，不是 JC 单源绝对 EV。

## 数据与方法

- srct 欧赔收盘轨迹（bronze/jc/sp_history 70,226 行带逐条变价 + 欧赔
  收盘共识）× JC SP × 赛果，十年。
- 同场次同向配对：分赔率桶（沿用十年扫描桶界），逐桶算两源实现 ROI，
  差值=侵蚀差；配对样本 n≥500/向，差 >2SE 过门。
- 两口径都报：侵蚀差原始值 + 「按欧收盘公允在 JC 报价」的假想 EV
  （诚实：JC 抽水 13% 摆着，侵蚀差>2pp ≠ 正 EV）。

## 判读边界（防过度解读）

- 本票判「校准缺口存在性」（六步门第②步证据），**不判正 EV**：侵蚀差
  显著 → 候选探针=JC 热门向/短赔向按欧收盘锚测实现差（新票人裁）；
  侵蚀差不显著 → 「用欧收盘做 JC 决策锚」的校准优势源关闭，H1 refuted。
- 与既有结论互证不动摇：FLB 在 JC 存在（已证）；本票只问两源差异。
