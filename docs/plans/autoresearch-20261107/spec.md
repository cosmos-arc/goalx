# autoresearch-20261107：持续探索链路（探索轨常设机制）

创建：2026-11-07。Status: ready-for-agent（票级见 issues/）。

本日用户定调："针对探索轨需一套机制，类似 autoresearch，应该有个持续
探索链路在跑。"——与 research/60 双轨制配套：验证轨=六步门（人裁），
**探索轨=本板：常设扫描器阵列自动产候选**，不再依赖手工跑分析。

## Problem Statement

四类 EV 源（信息差/校准优势/市场选择/微观结构）的候选发现目前是
 episodic 的：今天手工跑了市场校准表，明天没人跑就断。缺一个
"每天自己跑、自己留痕、自己报候选"的机制。

## Solution：扫描器阵列 + 发现台账 + 周报

1. **扫描器注册表**（DatasetSpec 先例）：每扫描器=名字/节奏/函数/
   统计门；日扫（昨日已结算数据，增量）+ 周报（显著性汇总）。
2. **发现台账** `edge_findings`（append-only）：scanner/segment/
   metric/n/置信区间/窗口/状态(new→promoted|dead)。台账是探索轨的
   唯一事实源，晋升=开验证票（六步门），死刑=计数留痕。
3. **接线现有积累器**：不少扫描器已有数据面在滚（评分层票02、CLV
   收盘锚、陈盘信号、停售探针、池期次），autoresearch 是把它们
   从"存数据"升级为"出发现"的汇流层，不重造采集。

## v0 扫描器清单（按数据就绪度排序）

- **S1 市场校准日扫**：昨日已结算场，市场去水概率 vs 实际（分价格带
  ×方向），滚动窗累计偏差；越过门（n≥N 且 |dev|>2SE）落台账。
  （今日十年版已手工验证过口径，负结果=长赔高估 3-4pp 无税后正桶。）
- **S2 模型校准/EV 实现**：评分层（票02，11-11 上线）落 forecasts
  对账——本扫描器=评分层报告面的台账化输出（不重算）。
- **S3 CLV 扫描**：纸面注 × srct 收盘锚逐注 CLV，分来源标签汇总
  （探针阵列上线后生效）。
- **S4 陈盘观测日**：每日 confirmed/fired 信号计数+命中率留痕——
  "有分辨观测日"的积累器，无信号日如实记零。
- **S5 滚存窗扫描**：每池期次兑付后回看奖池结构（是否滚存/池规模/
  派彩分布），滚存期 EV 结构标记。
- S6（后续）：LLM 信息差——情报时点 × 价格轨迹对齐扫描（NewsShock
  语料复用，测定价滞后非预测准确）。

## Implementation Decisions

- 先例复用：delay-audit 的 shadow-run/阶段门/停止条件模式；DatasetSpec
  注册表；晨检挂项；周报并入 daily-wrap 周版或独立 weekly flow。
- 台账表归 evaluation（ADR-0008）；扫描器纯只读分析。
- 显著性门 v0：滚动窗二项检验 p<0.05 + 最小 n，形式化随票 05。
- **节奏约束**：S1/S4/S5 数据已在、可先行；S2 等票02 上线；S3 等纸面
  注——机制先立、扫描器随数据面逐个点亮。

## Out of Scope

- 自动开验证票（晋升由周报人裁，不自动建票）；真金执行；新采集面。

## 二期：α 探索波 + EM-1 挖掘清扫（2026-11-08 用户裁定并入板）

来源：用户两轮框架校准——①「历史测不出⇒运行积累没必要」（搜索/验证
分离，向前数据只做幸存者终审+监测）；②「假设由挖掘产生，六条注册假设
失败≠覆盖证明」（撤回首版停机规则）。裁决全文见
`gate-adjudication-20261108.md`（§四为修订后停机规则）。

### Problem Statement

注册假设快筛（H1-H9）覆盖面有限；edge 存在性结论需要系统性的条件切片
挖掘支撑。同时，两个月历史搜索的阴性结果（预测线≈市场）不能外推到
未搜索面（书商定价差/时序/阵容/LLM 软信息）。

### Solution

**EM-1 边缘挖掘清扫**：目标变量从"预测赛果"换为**条件定价差**
`gap = JC 报价隐含概率 − 欧收盘公允锚隐含概率`，五 facet 切片清扫
（定价差/时序/基本面/LLM/池面），三段切分+试验账+效应量地板三纪律
护航；幸存者开预注册确认票→纸面探针（批次 γ 条件部署）。

### User Stories

1. 作为研究者，我想要 gap 作为挖掘目标变量（而非赛果预测），所以
   挖的是"JC 在哪定错了"而不是"谁赢"。
2. 作为研究者，我想要联赛×赔率段×玩法×时段×逐书的条件切片清扫，
   所以软慢书商的偏差口袋不会被全池平均稀释掉。
3. 作为账户所有者，我想要三段切分（搜索/验证/确认只碰一次），所以
   挖出来的口袋不是过拟合幻觉。
4. 作为账户所有者，我想要全量切片试验账+BH 校正，所以报告能区分
   "真幸存"和"试 N 个总会中几个"。
5. 作为账户所有者，我想要验证窗 EV≥+3% 且 >2SE 的地板，所以小效应
   不浪费确认窗与后续验证成本。
6. 作为研究者，我想要时序特征（drift/steam/调盘滞后）进 gap 模型，
   所以陈盘假设以可交易形式被检验。
7. 作为研究者，我想要阵容公布窗/xG/Elo 残差/赛程密度切片，所以
   公开基本面在 JC 的反应不足面被扫到。
8. 作为研究者，我想要 LLM 抽取跑在历史新闻上（无前视、成本有界），
   所以信息时滞窗口先证存在性再谈 EV。
9. 作为运维者，我想要 H4/H6 能历史回放的就历史回放，所以不为可回放
   的假设空耗运行积累。
10. 作为研究者，我想要池面 H7/H2 结论并入 EM 总账，所以探索结论单源。
11. 作为决策者，我想要全阴结论措辞为"已搜索空间内未发现"+清单，
    所以程序的阴性出口也诚实且可审计。
12. 作为账户所有者，我想要探针只在幸存者出现后部署（每注来源标签
    +CLV），所以向前运行数据是终审仪器不是搜索手段。

### Implementation Decisions

- 目标变量/协议/试验账住票 09（受控 append-only 文件，注册即冻结，
  报告可复算）；facet B/C=票 10、facet D=票 11 共用协议，不另立口径。
- 公允锚=srct 欧收盘去水共识（逐书+共识双口径）；无锚覆盖的 JC 面
  （如 hafu）标"未搜索"不硬凑。
- 票 08 第一段（H4 滞后切片）产出的特征直接喂票 10，不重算。
- 纯研究层：只读 research DB，报告落板内 `reports/`；不动生产代码与
  契约。幸存者确认票另行预注册（人裁）后才涉及工程面。

### Testing Decisions

- 研究缝=协议先行：试验账文件先落（人可查）再跑数；报告附切片清单
  与覆盖账可复算——这是本板对"测试外部行为"的等价物（结论可审计）。
- 复算性先例：十年回放/市场自校准扫描（research/51、edge 板 03）同款
  脚本+报告留档模式。

### Out of Scope

- 更深预测模型族（先验极差；H9 分族=edge 票 02 已覆盖其可辩护部分）。
- facet E（池面）新挖掘——并票 06/既有池结论，不重跑。
