# goalx 工作台 v2 · Spec

Status: ready-for-agent
Map: [map.md](map.md)（决策与外部依赖清单）

## Problem Statement

现有 UI 是"报表堆"：只看当天的场次列表、没有单场研究层、玩法无入口区分（只有胜平负一条暗线）、注额凭感觉固定。用户无法完成"从一场比赛到一个投注决定"的研究过程，也无法按玩法走各自的研究与策略路径（胜平负看模型×市场对照、进球看矩阵推导、14场任9 看覆盖策略——三者方法本就不同）。

## Solution

双轴研究工作台：**场次轴**（近 3 日列表 → 单场研究页：多 book 赔率明细/去水共识/模型概率/EV，基本面+AI 留位）；**玩法轴**（胜平负、进球推荐流 + 组合头部；14场任9 期次研究页）；**建议仓位**（只读：纸面 flat / 真金 ¼Kelly + 1–5% 上限）。继承前图（goalx-ui-redesign）全部设计系统、组件与质量基调。

## User Stories

**场次轴**

1. 作为操作者，我要浏览今天起 3 天的在售场次（按日分组），提前研究不赶当天截止。
2. 作为研究者，我点开一场比赛，看到每家公司各自的 H/D/A 报价明细，判断公司间定价分歧。
3. 作为研究者，我在同页看到去水共识概率与各书相对共识的偏差方向。
4. 作为研究者，我在同页看到我们自己的模型概率、EV 与资格判定，形成投注决定。
5. 作为新用户，基本面与 AI 研判区块明确标注"随 M3 到来"，而不是空缺或误导。
6. 作为操作者，从研究页能直接把选择带入选注篮，完成建注。

**玩法轴**

7. 作为胜平负玩家，玩法页把全部场次的机会按 EV×置信排序，我不用逐场翻列表。
8. 作为胜平负玩家，页头直接给推荐组合：具体场次、玩法、注数、预期收益，一键带入选注。
9. 作为进球玩家，总进球/比分玩法有自己的推荐流与组合头部（概率来自比分矩阵推导）。
10. 作为进球玩家，进球类口径（单关为主、矩阵推导）在页内有词典可查的标注。
11. 作为 14 场玩家，选定一期后看到 14/9 场每场的三向概率与推荐选择标记。
12. 作为 14 场玩家，我得到三档额度（保守/标准/激进）的投注建议，各档含注数与理由。
13. 作为 14 场玩家，AI 证据总结（为何这样研判）、目标金额反推、搏冷模式有明确占位，我知道它们会来。

**仓位**

14. 作为操作者，建注时看到建议注额与理由（档位、上限截断说明），人工确认后落注。
15. 作为纸面期用户，系统一律建议 flat 固定注——任何比例策略在前瞻 skill 过线前不启用。
16. 作为真金用户，建议仓位为 ¼ fractional Kelly 且单注不超过 bankroll 1–5%，EV≤0 时建议 ¥0。

**横切**

17. 作为复盘者，玩法页的推荐组合与历史页口径可对账，纸面/真金隔离不变。
18. 作为用户，双主题、三态空状态、axe 零严重违例、移动端底线全部延续。

## Implementation Decisions

- **导航**：总览 / 场次 / 玩法（组：胜平负·进球·14场任9）/ 投注 / 历史 / 验证 / 资金；词典留次级。
- **场次列表 3 日**：fixtures 表已含多日在售数据；端点加日期范围参数（contract 增量）；`/today` 路由让位重定向。
- **研究页**：新增 per-book 赔率端点（odds_snapshots 已逐书存储）；共识/模型概率/EV 复用现有口径；基本面/AI 用 EmptyState not-available 留位。
- **MarketGroup 三分类**（已进 CONTEXT.md）：胜平负类(had/hhad)、进球类(ttg/crs)、奖池型(ttt14/pick9)；半全场不呈现。
- **进球类概率**：比分矩阵（ADR-0006）推导；ingest 补竞彩 ttg/crs 赔率（复用 sporttery 链路）。
- **组合 v1 引擎**：纯函数——EV×置信排序 top-N；约束单注 1–5% bankroll、同场不重复、串关 ≤2 腿；预期收益按共识口径计算并标注。
- **仓位建议**：只读端点 + UI；规则见用户故事 15/16；倍投/斐波那契等 progression 系否决（不改变 EV 只重排破产路径，且污染 CLV/skill 统计——research/staking-plans.md）。
- **14场任9 骨架**：概率矩阵 UI + 推荐/搏冷标记 + 三档额度（复用仓位规则）；彩池数据外部依赖（goalx-quant 立票），无数据空态诚实标注。
- **亚盘**：暂不引入（The Odds API 足球仅 h2h）；零成本评估 draw_no_bet/btts 覆盖率留作后续（research/odds-consensus-methodology.md）。
- **contract 增量清单**：fixtures 日期范围、per-book odds、ttg/crs 玩法端点、stake-advice、（外部）pool——全部 contract-first，零破坏。

## Testing Decisions

- 只测外部行为；沿既有接缝（上轮用户已确认，无新接缝）：页面级 RTL+MSW、Playwright e2e + axe 双路径断言（expectNoSeriousAxeViolations）、组合引擎/仓位计算/概率推导做纯函数单测。
- 先例：前图各票（today/overview/history 等 page.test + paper-loop spec）。

## Out of Scope

自动下注/自动改单、真亚盘数据源、目标金额反推与搏冷生成器（v2 雾区）、AI 生成内容（等 M3）、基本面数据源（等 M3）、登录/多租户、i18n、破坏性 API 变更。
