# 12 回测与纸面验证协议设计

Type: grilling
Status: resolved
Blocked by: 08, 09

## Question

（由「回测引擎设计」雾毕业——03/02 已闭环，问题现已可精确表述。）与用户一起敲定验证子系统设计（HITL grilling，可配 throwaway prototype）：

- 回测数据回放范围：football-data.co.uk 的赛季/联赛切片、Pinnacle 收盘价代理竞彩官方盘的**校准方法**（竞彩调盘不可得，如何建立「竞彩赔率 ≈ f(欧洲收盘)」的映射与误差带）。
- 回测引擎形态：事件回放接口（时点数据 → 模型预测 → 模拟下注 → 结算）、防前视（look-ahead）与数据泄漏的约束。
- 纸面验证协议：纸面注单与真实规则的一致性（含无效场次退款规则）、每日快照时点、指标窗口（滚动 yield/CLV/RPS）。
- 通过线与止损线：纸面期多久/多少注才放行真金（与 10 的规则衔接）、各指标的通过阈值（对市场 skill ≥ 0、CLV beat rate 60%+）。
- 回测与纸面的统计口径统一（同一套 Settlement/指标代码，避免两套账）。

产出：验证协议设计段落（进 spec），含「欧洲收盘代理竞彩」校准方案的 ADR 草案。

## Answer（2026-09-13 闭环，用户裁决回测范围 = 近三季）

产物：[ADR 0007](../../../../docs/adr/0007-euro-close-proxy-backtest-baseline.md)（欧洲收盘公允基准 + haircut 代理 + walk-forward/防前视）。

**验证协议 v1**：

1. **回测范围（用户拍板）**：五大联赛 2023-2026 三季 walk-forward（约 5,700 场）。取舍已记录：样本减半→显著性边际时扩到 2020-26 六季；杯赛/欧战不进首轮回测（动机噪声+欧赔历史薄）。
2. **公允基准与代理**（ADR 0007）：fair = Pinnacle 收盘 Shin 去晦（PSC 78% 非空，AvgC 兜底）；模拟竞彩价 = fair × haircut（初始 −10% ± 5~7% 误差带，源自 08 实测），纸面期配对样本持续校准替换默认值。
3. **防前视铁律**：walk-forward 逐轮重估、特征仅取时点快照（ADR 0001）、时间切分不 shuffle、收盘价只作结算基准不进特征；LLM 线不回测只前瞻。
4. **口径统一**：回测模拟下注、纸面、实盘共用同一套 Settlement/指标代码（ADR 0002 的直接推论）；2串1 模拟按 EV 阈值 + 第二腿下限公式（10 号参数）。
5. **纸面协议**：每日快照时点沿用 09（kickoff −30/−10/−1min 尽力 + 收盘对账）；纸面注单含未购建议（06）；指标窗口 = 滚动 100 注 + 累计双口径；无效场次按官方规则结算（01）。
6. **通过线**：沿用 10 号三条件（CLV≥200 注 beat≥60%、skill≥0、复核无系统性错误）；回测预通过线 = 对市场 skill ≥ 0（RPS 配对检验 p<0.1）+ 陈盘信号触发频率达到可统计量级（否则方向 A 需重新评估）。
7. **滚存特殊性**：任9/14 滚存信号无法从 football-data.co.uk 回测——历史奖池数据（500.com 每期池/滚存/中奖注数）列为实现期数据任务（08 已留缺口），滚存 EV 只做纸面前瞻验证 + 滚存轮加码上限校准（10 号）。

对下游：11 号 spec 的「验证子系统」章节以此为准；全部前置票已闭环，11 是最后一张。
