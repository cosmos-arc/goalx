# 14 可实现优势（Edge）与预期收益：学术依据 + 主攻方向

Type: research
Status: resolved

## Question

（用户 2026-09-12 追加。）有学术依据的可实现 edge 与预期收益是什么？建议的主攻方向及各方向预期收益？系统需要内建「价值预估」与「成本预估」功能——具体要估什么、怎么估？供 09/10/11/12 的设计与路线图使用。

## Answer

详见 [research/14-edge-and-expected-returns.md](../research/14-edge-and-expected-returns.md)。要点：

1. **硬约束**：竞彩 takeout 27% → 打平需相对公允概率 **+37% 的相对优势**；长期盈利者 CLV 也只有 1-3%。结论：**「模型跑赢市场」不能作为竞彩固定赔率的主盈利引擎**。
2. **主攻方向 A（竞彩）：陈盘捕捉（stale-line capture）**。竞彩为官方垄断固定赔率、调盘慢（机制同希腊 OPAP 垄断市场，学术已证实此类市场开收盘漂移可预测），用实时 sharp 线（Pinnacle 去晦）对照竞彩锁定赔率，捕捉官方调盘滞后的错价。触发时单注预期 +1~5%，触发频率低（每轮 1-5 场量级）。
3. **主攻方向 B（任9/14）：滚存轮 + 反共识覆盖**。学术支撑最硬：Ziemba (2020) 滚存 EV 分解（EV = P(独中)×(滚存+池)−成本）+ 奖池 FLB 理论（Ottaviani & Sørensen 2010）+ Clair & Letscher (2007) 奖池最优策略。常态轮 EV≈−35%（takeout），**滚存轮是结构性 +EV 窗口**；澳客人气/专家分布数据（票 13）直接支撑反共识覆盖。预期：参与的滚存轮 EV 可转正（+5~20%/轮量级，重尾方差）。
4. **ML/LLM 双线的角色**：概率估计基座与验证基准（对市场 skill ≥ 0），不是独立盈利柱。组合拳预期收益：**最好情形组合 yield 低个位数百分比**，大多数轮次空仓（不投负 EV 注本身就是价值）。
5. **价值预估功能**：每候选注输出——模型概率（bootstrap 置信区间）、市场隐含概率（Shin 去晦）、EV%、成本调整后 EV、Kelly 注额、双线一致性分层；奖池轮输出滚存 EV 计算器（模拟 P(独中)×(滚存+池)）+ 公众份额估计（澳客数据）。
6. **成本预估功能**：月固定成本模型（数据 $19-49 + LLM $1-10/轮 + 本地 0）系统内记账；每轮边际成本；**盈亏平衡换手率计算器**（如月成本 $40、yield 2% → 需月换手 $2,000 才回本）；成本分摊进 cost-adjusted EV 作为下单闸门。
