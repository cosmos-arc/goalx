# 17 赛事范围与分层投入定稿

Type: grilling
Status: resolved

## Question

（用户 2026-09-12 发起。）系统值得投入的赛事范围怎么定？决定 ML 训练分池、LLM 情报预算分配与陈盘扫描对象。

**用户已表达的倾向（作为既定输入）**：Tier 1（主动投入：ML 训练分池 + LLM 情报线 + 陈盘扫描重点）= **欧洲主流联赛 + 杯赛，含欧冠与欧联**（即五大联赛 + 欧冠 + 欧联）。

**待现场裁决的子问题**：

1. Tier 1 是否扩展：+欧协联 / +国家队赛事（欧国联、世预赛、世界杯/欧洲杯/亚洲杯——大赛期竞彩量最大但跨赛季样本少）/ 全主流包？
2. 竞彩开售但非 Tier 1 的赛事（荷甲/葡超/土超/日职/澳超/巴甲/美职联/中超）怎么处理——（a）被动覆盖：ML+EV 扫描跑、LLM 情报不上、任9/14 出现时照常参与（推荐：冷门赛事调盘更懒、陈盘机会不放弃，成本低）；（b）全覆盖；（c）完全忽略。
3. 杯赛动机/轮换场景（欧冠/欧联小组末轮、淘汰赛）是否设为 LLM 情报线重点触发条件（推荐：是——杯赛动机是 ML 最弱、LLM 最强的场景）。

**证据背景**（自 01/02/13/15）：任9/14 的 14 场由官方选取（以欧洲主流为主，与倾向一致，奖池线被动跟随即可）；五大+欧冠+欧联的数据/回测/情报支持全满；冷门赛事历史赔率与 xG 薄但竞彩调盘更懒（陈盘机会与情报缺口的矛盾 → 分层处理）。

**实现含义**：赛事范围做成配置（tier 标签）而非硬编码；Dixon-Coles 按联赛分池训练（不做跨联赛球队强度比较）；tier 决定 scout/analyst 的调用预算。

## Answer（2026-09-12 用户确认闭环）

用户确认 Tier 1 = **五大联赛 + 欧冠 + 欧联**（用户原始倾向），并采纳三个建议：

1. **Tier 1 不扩**：欧协联、欧国联/世预赛归 Tier 2；友谊赛直接排除（动机噪声最大）。**大赛（世界杯/欧洲杯/亚洲杯）临时升 Tier 1**——tier 是配置，大赛 = 配置切换事件，不为低频赛事常态付费。
2. **Tier 2 被动覆盖**：ML 分池训练 + EV/陈盘扫描 + scout 小模型情报照跑（边际成本≈0），仅 analyst 大模型复核留给 Tier 1。冷门赛事（日职/澳超/中超/巴甲）竞彩调盘最懒，是方向 A 陈盘的主矿区，不放弃；数据薄的场次靠 bootstrap CI 宽 → Kelly 自动小注控制。任9/14 出现 Tier 2 场次时照常参与。
3. **杯赛情报倾斜**：欧冠/欧联小组末轮、淘汰赛、国内杯赛爆冷窗口设为 analyst 复核的优先触发条件（gate 路由加「赛事阶段」特征，末轮/淘汰赛放宽触发阈值）——ML 最弱、开放检索最强的场景（票 05 结论的应用）。

分层表：

| 层 | 范围 | ML 分池 | EV/陈盘 | scout | analyst |
|---|---|---|---|---|---|
| Tier 1 | 五大+欧冠+欧联（大赛临时升入） | ✅ | ✅ 重点 | ✅ | ✅ 杯赛优先 |
| Tier 2 | 竞彩开售其余赛事（含欧协联/国家队常规/中超等） | ✅ | ✅（陈盘主矿区） | ✅ | ❌ |
| 排除 | 友谊赛、非开售赛事 | ❌ | ❌ | ❌ | ❌ |
