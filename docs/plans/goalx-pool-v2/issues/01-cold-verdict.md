# 每场搏冷判定+标注升级

Type: impl
Status: resolved
Blocked by: none

## 问题

彩池页现有"搏冷"标记是前端按份额低随手标的，不是价值判定；用户要"每场是否值得搏冷"的模型化预测。

## 范围

1. 判定规则定案：选项为冷 = 份额 < 25% 且 EV > 0（阈值进常量）；"值得搏冷" = 该场存在冷选项且其 EV 比最优选项 EV 高（即牺牲命中换赔率是正期望的）
2. 前端：每场槽位的搏冷标记改为价值判定（EV 驱动），点击/悬浮展示理由（概率 vs 份额 vs 估计赔率）
3. 词典新词条：搏冷价值（冷门 EV 的判读方向与数字实例）
4. 口径文案更新

## 不做

- 不训练独立冷门分类器（见地图 Notes）；不建历史冷门命中率回测（等信号实证）

## Answer（2026-09-19）

PR #31：判定=份额<25% 且 EV>0 且优于推荐向；不训独立冷门分类器（决策记地图 Notes）；词典 20 号词条"搏冷价值"（glossary.md 准绳同步）。
