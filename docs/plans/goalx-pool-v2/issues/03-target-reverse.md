## 问题

用户想输入目标奖金金额，系统反推选票（场次/选项/注数）。

## 范围

1. 后端 `POST /api/v1/pool/target-plan`：入参 period_no + 目标金额 + 风险档（稳/中/搏）；出参推荐票面（14场全选或任9 选 9 场贪心）+ 估计派彩 ≥ 目标 + 命中概率 + 建议注数（目标 ÷ 估计派彩，向上取整到 2 元注）
2. 任9 选场 v1：按 log(p_max) 和最大化命中概率贪心选 9，再用冷门替换抬派彩到目标（复用 02 的替换逻辑）
3. 前端：目标金额输入 + 风险档 + 结果票面预览 → 提交纸面篮
4. 诚实边界：估计派彩是份额口径（65% 返奖率），实际派彩随最终池变；文案明示"估计"

## 不做

- 不承诺目标达成（输出的是"若命中估计得 X"），不接真金
