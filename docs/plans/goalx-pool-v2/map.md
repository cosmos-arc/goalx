# goalx 彩池玩法 v2（迭代 2026-09-19）

目的地：14场/任9 从"看概率"升级到"可执行"——每场搏冷价值判定 + 搏冷组合生成器 + 目标金额反推，接三档额度建议与纸面池票。

## Notes

- **搏冷价值判定（用户提出"每场都可以有特定模型预测下"）的落点**：信号 = 模型概率 vs 公众份额的背离，即既有 EV 公式 `p × (0.65/share) − 1`。冷门选项 EV 为正且显著 → 值得搏冷。这是每场每选项的模型化预测（p 来自 DC 模型或欧指去水），**不单独训练冷门分类器**——冷门标签就是"模型概率显著高于份额"，再训一个模型只复制现有信息（YAGNI）；若实证信号弱（连续多期冷门 EV 为负却命中），再立票训练。
- 诚实口径保留：返奖率 65% 假设、未建模 price impact/分彩风险，caliber 文案随生成器一起展示。
- 任9 的"选哪 9 场"本身是生成器子问题：v1 贪心（按命中概率 × 冷价值排序选 9），不做全局优化。
- 三档额度复用 betting/staking.py；提交走既有 pool-slips 纸面通道。
