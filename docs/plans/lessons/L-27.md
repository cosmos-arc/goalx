# L-27 J1「联赛排平」条件不可用（2026-11-10 票 24）

**判决**：构票条件只留滚存/盘口两轴，联赛身份不作平局条件轴；「意甲出平/德甲不出平」类 folk 语言入库即证伪。

**死因与证据**：主带 20-30% 联赛极差 2.78–3.23pp=纯噪声期望（2.94–3.38pp），门内对 95% CI 上界 ≤4.06%；意甲−德甲主带 −0.52~−0.61pp（方向反 folk）；边际差 ≈3pp 且几乎全由赔率带组成解释，「意甲 33% vs 德甲 21%」在库内边际上即不存在（实测 25.6% vs 25.0%，psc 十年面）。M6 末 3 轮×无欲对峙无平局抬升（n=319 过门，主带 −0.60pp p=0.59 单侧；合并 +1.56pp p=0.26 附注口径）。

**边界**：10-20/30-40 尾带逐对功效不足以排除 7pp；葡超 10-20 平局短缺双锚同号不过校正（反排平方向）留观。
