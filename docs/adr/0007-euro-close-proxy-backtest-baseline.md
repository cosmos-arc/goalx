# 回测以欧洲收盘为公允基准，竞彩价用校准 haircut 代理

竞彩官方调盘历史不可回溯（票 01），回测无法直接使用真实竞彩时序价格。决定：回测公允基准线 = Pinnacle 收盘价 Shin 去晦（football-data.co.uk 的 PSCH/PSD/PSCA 列，缺失行用 AvgC 系列兜底，票 08 实测 78%+100%）；模拟竞彩价 = 公允概率 × haircut，haircut 初始取 −10%、误差带 ±5~7%（来自票 08 对 26 场竞彩 vs 欧洲共识 EV −5%~−17% 的实测），并由纸面期的真实配对样本（竞彩快照 vs 同场欧洲收盘）持续校准替换。回测一律 walk-forward：模型只用 kickoff 前可得数据（特征取自 ADR 0001 的时点快照），收盘价只作结算基准不进特征；LLM 线无历史状态，不参与回测，仅前瞻验证（票 05 结论）。
