# 回测以有质量标记的欧洲赔率为基准，合成价仅用于模型实验

历史决策采用Pinnacle收盘Shin（缺失用AvgC）及折价代理，因缺少真实竞彩报价时序，先建立模型实验；该取舍保留，但2026-09-13审视纠正以下边界。

设市场估计概率为p、折价比例为h，模拟十进制赔率为`O_sim=(1-h)/p`；原文“公允概率×haircut”单位错误。初始h=0.10是实验情景，不是已完成前瞻校准的参数。haircut配对应固定as-of及时间容差，防止市场移动混入机构折价。

[football-data官方](https://football-data.co.uk/data.php)明确警告2025-07-23后Pinnacle开盘与收盘数据系统性陈旧。基准必须按日期/来源质检，不能只因PSC非空就视为可靠sharp收盘；对照另建run并保留旧结果。PSC字段为PSCH/PSCD/PSCA，AvgC也须保留来源及质量限制。

模型训练继续walk-forward；但合成价选注、周内最终收盘挑串关没有真实竞彩销售资格与共同购买时点，不能称可执行陈盘回测。收盘不是结算事实，开奖才决定输赢；收盘可作预测比较或CLV基准，不能变成较早决策时已知输入。当前had-only实验保留，不据此证明A方向有效或无效。

正式前瞻用严格赛前、完整且质量可解释的报价，记录源更新时间与观测时间；晚到或缺失不计正式CLV。LLM仍只前瞻。以上为修订约束，现有采集、校准与看板须在可信纸面闭环实施中对齐。
