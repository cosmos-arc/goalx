# ADR-0010: 源T 轨迹语料回填——范围解耦、双源 xG 互补、数据集不入库

日期：2026-09-23
状态：已接受（research/20 二轮 grill 定案；落地票承接；回填窗口与量级经 ADR-0011 修订）

## 背景

源T（titan007 族，见 `.scratch/goalx-quant/research/20-source-t-feasibility.md`）是
免费世界里唯一能拿到多赛季逐庄"开→收"赔率轨迹的来源（fdhist 只有收盘列、The Odds
API 免费档无历史、源B 2026-09 起才积累）。2026-09-23 grilling 决定回填轨迹语料
（原定 2020→今；**ADR-0011 修订为 2017/18 季初起·分层深度·分三批**），其中三个边界
裁决难以逆转、且未来读者会问"为什么这么做"。

## 决策

1. **采集范围与建模范围解耦**。轨迹语料按 CorpusScope（15 项赛事：五大+英冠+
   荷甲+葡超+土超+比甲+苏超+瑞超+挪超+欧冠+欧联）采集；建模线维持
   TIER1_COMPETITIONS（五大+荷甲）不动。语料覆盖服务竞彩生产域与轨迹研究——
   采进来≠必须进模型；担心轮换/噪声污染模型时砍建模范围，不砍语料范围。
   增删联赛改一处清单常量（对齐票 46 的 FD_COMPETITIONS 模式）。
2. **xG 双源互补，不换防**。Understat 维持历史 xG 主源（五大+俄超、2014/15 起，
   票 45 现状）；源T xG 自 2025 起稳定（2024/25 季中起部分场次，审计见
   research/20 §九），承担三项独家增量：CorpusScope 中 Understat 不覆盖的 9 项
   联赛的唯一 xG 源；维度扩展（运动战/定位球/非点球拆分+xGOT）；整块 47 键高级
   统计。五大 2025+ 双源数值交叉验证。落库按场记 xG coverage（EXPECTED_GOALS
   键有无），缺 xG 不跳过整页（工程定则 4：没有数据≠没有 xG）。
3. **回填数据集不入开源仓库**。源T 条款禁复制/转售/商用——采集脚本与表结构进
   repo，回填产物（原始响应与派生数据集）仅存本地数据库，不提交。采集姿态：
   robots-clean 端点（1x2d.js、Over 日页、vip 变化/统计页——vip/1x2d/sports/
   data 主机无 robots 限制；bf 主机禁带参路径故弃用其带参接口）、3s±1s 抖动、
   夜间窗口、日预算上限、日页 checkpoint 断点续传。

## 后果

- CorpusScope 15 项中 11 项与 fdhist 十年语料重叠：验收用 fdhist 场次对账 +
  PSC×cid177（Pinnacle）收盘对账；瑞超/挪超各扩一行 FD_COMPETITIONS 后同法对账。
- 语料内时点数据 published_at 取源端留痕时间（changeTime 等），observed_at 为
  抓取时间（工程定则 2）；身份绑定后置，映射走确定性键（定则 1）。
- 源T 是"容忍而非合同"：若未来收紧（改版/限流），语料退化为只增不减的既有资产，
  不阻塞主线；届时再评估飞鲸 B2B 合法购买路径。
- 推翻本 ADR（CorpusScope 大改或 xG 换防）需新 ADR。
