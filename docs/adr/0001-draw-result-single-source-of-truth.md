# 开奖为唯一事实源；预测与赔率为 append-only 时点快照

竞彩官方调盘历史不可回溯（票 01），且纸面验证/回测必须防前视与事后修改（票 12）。因此：DrawResult（官方开奖）是系统唯一的事实源；Forecast 与 OddsSnapshot 一律按（来源、时点）追加存储、不可变。每次 Forecast 落库时做内容哈希存证（借鉴 theopenmodel 的可验证预测注册），作为纸面期"预测先存证、赛后对账"的基础。

## 2026-09-13 澄清

DrawResult是**开奖与结算**事实源，不代表手工导入未经核验就等于官方事实。更正保留来源、旧新值和原因，已结记录通过重算与差额冲正更新，不能只覆盖结果而留下旧盈亏。

快照区分源更新时间、本机观测时间与入库时间；历史回放保留返回的实际时点，不冒充实时观测。内容哈希不证明系统在某时刻已知数据，正式Forecast仍须在开赛前生成并校验训练窗口。

实施状态：开奖更正审计、事务重算及差额冲正已随[结算生命周期修复](https://github.com/cosmos-arc/goalx/pull/4)合并；快照时间及前瞻资格仍待实施，不能因更正路径完成而视为全部约束已落地。剩余交接见[可信纸面实施安排](../plans/trusted-paper-handoff.md)。
