# 比分矩阵（10×10）为规范概率表示

双线预测的统一输出格式采用 Dixon-Coles 风格的 10×10 比分概率矩阵作为 canonical 表示，各玩法概率（胜平负/让球/总进球/比分/半全场/任9连乘）一律由矩阵推导生成视图，而非各市场独立建模。取舍：单市场向量更简单直接，但玩法间概率会不一致（同一场比赛总进球与比分的隐含概率对不上），奖池覆盖优化（Clair-Letscher）与 LEAP 融合都需要一致的联合分布；矩阵是满足一致性约束的最小表示。半全场等需要半场分布的玩法，以 λ 半场拆分（≈0.45λ）生成扩展矩阵，作为矩阵的附属视图而非独立模型。

## 2026-09-13 适用范围修订

上述统一性仅直接成立于全场比分相关视图had/hhad/ttg/crs。全场矩阵不能唯一决定半场轨迹；半全场的λ拆分是额外近似，不能宣称与完整DC联合过程一致。跨比赛连乘也需要独立性假设，不能由单场矩阵自动得到组合投注份额。

当前回测与新纸面产品先限had。真实国际totals/handicap只提供额外市场约束，其结算语义不等同竞彩精确进球桶/三向整数让球；接入报价后仍须验证映射、可识别性和校准，再决定是否恢复其他玩法。保留现有矩阵组件，暂缓新增玩法认证。
